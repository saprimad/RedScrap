What it does

From Reddit discussion to research dataset.

Built for researchers working with public Reddit conversations, with collection parameters that can be documented as part of a reproducible method.

01 / TARGET

Focused searches

Set a subreddit, terms and a time window that match your research question.

02 / COLLECT

Posts and comments

Gather discussion material while keeping the thread context useful for later review.

03 / EXPORT

Structured output

Export comment-level records to Excel, or generate an exploratory PDF report.

Getting started

Run RedScrap on your computer.

The source repository contains the latest code and setup guidance. For academic research, apply through the Reddit for Researchers programme. Keep any approved access credentials private.

  1. Read the repository instructionsCheck the current requirements and installation steps on GitHub.
  2. Apply for research accessFollow the Reddit for Researchers programme and use only the access and methods approved for your project.
  3. Configure and collectEnter your own credentials on first launch, define a search, then export to Excel or PDF. Never publish reddit_config.json or client secrets.

Grant-funded collaboration

If your study has grant funding, we can discuss a proposed work package. Fee-based extraction can proceed only with the required Reddit permission and institutional approvals.

Academic data collection requires appropriate Reddit for Researchers access and research ethics review. Reddit treats research or data access for fees as commercial use requiring its permission and a contract. Scope and feasibility are assessed before any commitment; the researcher remains responsible for interpretation and analysis.
